# 🎬 Movie Website

A full-stack movie website built using Django.

## 🚀 Features
- Browse movies
- Movie details page
- Reviews and ratings
- Watchlist functionality

## 🛠 Tech Stack
- Backend: Django (Python)
- Frontend: HTML, CSS, JavaScript
- Database: SQLite

## 📌 Future Improvements
- User authentication
- Recommendations system
- Improved UI
